### What I learned

During this project, I practiced configuring structured CSS tokens using custom properties for theme colors and responsive font sizes.

Here is the `:root` structure used:

```css
:root {
  --color-green: hsl(75, 94%, 57%);
  --color-white: hsl(0, 0%, 100%);
  --color-grey-700: hsl(0, 0%, 20%);
  --color-grey-800: hsl(0, 0%, 12%);
  --color-grey-900: hsl(0, 0%, 8%);
  --font-family: 'Inter', sans-serif;
}
